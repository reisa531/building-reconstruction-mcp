# 建筑材质与光照

使用 `building-reconstruction` MCP 的 `map_materials`。输入为 geometry NPZ、带 provenance 的实测点云、目标版本 palette、明确 4×4 坐标变换和 policy。完整参数见交付包 `C:/BuildingWorkspace/reconstruction-kit/README.md`。

只采 provenance=0 的点，近邻中位数估色；超过阈值保留基础材质。每个构件限制允许的方块族，不把全局近色匹配用于所有构件。几何保持规则且对称，风化杂色无需严格镜像。

默认方向项去除强度 .5、最大对数增益 .18；拟合包含高度项但不消除高度趋势。默认明暗残差保留 .25、色度残差保留 .15，亮度倍率 [.85,1.15]。比例控制残差强度，不代表改色方块占比。固定输入得到确定结果，无随机撒色。

此算法只有数值 RGB 的启发式光照估计，不能声称恢复真实材质反照率。不开 AI 生成式关灯，不烘焙新的太阳阴影，不自动去掉建筑真实暖色。原彩色数据不覆盖，材质派生结果另存。

验证材质前后 occupancy hash、开口/玻璃锁定、实测颜色支持率和每类构件材料分布。光照或杂色过强先缩小参数和材质族；无有效实测点时全部回退，不编造来源。
