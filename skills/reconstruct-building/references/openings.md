# 开口与负空间

先确定楼层、开间、立面平面与墙厚，再将门窗组织成规则阵列。阵列规律用于提出缺失窗位，照片或扫描支持的窗位标实测，复制位置标推断；必要时保留不确定状态直到确认。

空洞不等于缺点：玻璃反射、透光、遮挡、过曝会让点云稀疏；看不到点不能自动挖窗。室内通行空间、挑空、连廊、底部架空和塔身平台孔也需显式保护。

生成顺序：墙体/框架/楼板/梁柱 → 门窗和通道统一扣除 → 玻璃填充锁定 → 材质映射。空气约束和玻璃约束贯穿后续全部步骤。任何补洞、闭运算、连杆补全或碎片修复都必须在完成后重新应用开口并验证。

当前工具拒绝完全未碰到实体的开口，并检查保护格的逐格填充。低分辨率下窗宽/高/墙厚至少要能留下体素；若尺寸不足，调整整体缩放或规则化模数并记录比例改动。不能仅凭渲染里一个黑点就报告开口存在。

验收：门口与楼梯口通行尺寸；窗格宽高及间距；窗框不穿过玻璃；玻璃与空气分开计数；每层平面对齐；开口处的 protected_air 与最终占据体素交集为空；玻璃的 expected_opening_palette 与逐格实际 ID 相同。玻璃保护只表达建筑语义，不是 Minecraft 透明材质的物理光照模拟。
